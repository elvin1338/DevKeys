DevKeys — интерактивный справочник разработчика
Версия 1.1

Функции:
- справочник горячих клавиш, команд терминала, Git, Python, C++, Java, HTML и CSS;
- поиск по названию, команде и описанию;
- добавление записей в избранное;
- копирование команд в буфер обмена;
- режим обучения с вопросами и вариантами ответов;
- история последних просмотренных команд;
- переключение светлой и тёмной темы;
- очистка истории и избранного в настройках.

Данные хранятся локально на устройстве. Приложение работает офлайн.

Открытие: Android Studio -> File -> Open -> выбрать папку DevKeys,
в которой находятся settings.gradle и build.gradle.
Сборка: Build -> Build Bundle(s) / APK(s) -> Build APK(s).
